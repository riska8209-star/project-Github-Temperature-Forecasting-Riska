Project Machine Learning — Probabilistic Temperature Forecasting

Author: Riska

Deskripsi Project
Project ini menggunakan Machine Learning untuk memprediksi suhu (temperature forecasting) dengan pendekatan quantile regression.
Model yang digunakan adalah HistGradientBoostingRegressor dari Scikit-learn.

Tools dan Library:
Python
Jupyter Notebook
Pandas
NumPy
Matplotlib
Scikit-learn
Dataset

Dataset yang dibutuhkan:
train.csv
test.csv
sample_submission.csv

Tahapan Pengerjaan:
Data loading dan data understanding.
Data cleaning.
Exploratory Data Analysis (EDA).
Deteksi outlier menggunakan metode IQR.
Feature engineering dan preprocessing.
Pemodelan Machine Learning.
Evaluasi menggunakan MAE, RMSE, R², dan Pinball Loss.
Pembuatan file submission.csv.

Cara Menjalankan:
Instal Python dan Jupyter Notebook.
Siapkan file dataset yang diperlukan.
Instal library yang dibutuhkan.
Buka Projectriska.ipynb.
Jalankan setiap sel notebook secara berurutan.
