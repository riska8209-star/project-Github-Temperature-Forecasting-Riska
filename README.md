Project Machine Learning — Probabilistic Temperature Forecasting

Author: Riska

Deskripsi Project
Project ini menggunakan Machine Learning untuk memprediksi suhu (*temperature forecasting*) dengan pendekatan quantile regression.

Model yang digunakan adalah HistGradientBoostingRegressor dari Scikit-learn.

Tools dan Library
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

Dataset
Dataset yang dibutuhkan:
- train.csv
- test.csv
- sample_submission.csv

Tahapan Pengerjaan
1. Data loading dan data understanding.
2. Data cleaning.
3. Exploratory Data Analysis (EDA).
4. Deteksi outlier menggunakan metode IQR.
5. Feature engineering dan preprocessing.
6. Pemodelan Machine Learning.
7. Evaluasi menggunakan MAE, RMSE, R², dan Pinball Loss.
8. Pembuatan file submission.csv.

Cara Menjalankan
1. Instal Python dan Jupyter Notebook.
2. Siapkan file dataset yang diperlukan.
3. Instal library yang dibutuhkan.
4. Buka Projectriska.ipynb.
5. Jalankan setiap sel notebook secara berurutan.
